# AGENTS.md — {{project}}

Instructions for coding agents working in this repository. Humans: see README.md.
Keep this file short. Every line should change what an agent does.

## Working agreement
- Make the smallest change that solves the task. Do not reformat or rename unrelated code.
- Ask (or stop and report) instead of guessing when requirements are ambiguous.
- Never commit secrets, tokens or personal data. Use environment variables and `.env.example`.
- Do not add a new dependency without saying why in the change description.
